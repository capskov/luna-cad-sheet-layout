# Luna CAD Sheet Layout

**Luna CAD 智能体套图排版技能**

**An AI Agent Skill for AutoCAD Sheet Layout, Title Blocks & Drawing Index Management**

目标：设计内容已完成，Agent把它组织为可用图幅，挂接已确认的最新版图框外参，配置比例与取景，维护图签和目录的一致性。也处理续作、查图、增页、减页、改名及重新编号。不是仅靠脚本无人判断的一键套框。

## 自选指导密度

- **分步模式（默认）**：适合算力或上下文有限、CAD经验不足、首次接手本技能的Agent。读[分步操作](references/guided.md)，每次只处理一个明确动作，按需查[踩坑索引](references/pitfalls.md)。依靠检查点续作，避免反复推理整套工程。
- **简明模式**：能独立理解图面、排障和可靠操作的Agent采用下方主线；只在碰到具体问题时查详细资料。不要求读完所有经验，不强制照抄步骤。
- 根据本轮能力、剩余预算与错误情况自行选择或切换，在工作记录写一句选择及原因；不只凭模型名称判断，也不要求换模型或另开智能体。

两种模式目标与安全边界一致，区别是指导密度。不得把历史A3尺寸、坐标、图号、字体或某项目页数当成通用配置。

## 简明主线

1. 清点目录、DWG、布局、图签、外参及未完成项；建立本轮[页清单](references/catalogue.md)。按真实内容匹配目录，保留正确页面。
2. 从候选中确认图框版本。最新日期是线索：以用户指定、文件名修订日期及版本说明为依据；修改时间不单独证明正式最新版。不确定且影响选择时再问。
3. 先读[后端能力与衔接](references/backends.md)，选择本轮执行通道。底座已有操作优先复用；缺口如实说明，不把COM执行写成底座MCP通过。
4. 根据实际尺寸确定纸幅、模型单位、视口取景和工程比例；在明确布局挂接外参、维护图签、配置工作视口并锁定。具体原生接口见[COM操作](references/native-com.md)。分幅、比例、美观由Agent判断。
5. 按本次要求抽查代表图幅及特殊类型，实际看CAD图面或渲染PDF；通过的方法可用于同类页面，不逐对象重复验证。最终图号、图名、页数与目录作一次轻量核对。
6. 保存可追踪的修改，报告已完成/待补页面、外参依赖、实际后端、抽查范围及限制。结果与计划分开记。

## 执行边界

- 对用户授权工作副本操作，精确匹配DWG完整路径；同一图纸同一时刻一个写入者。保留正式图和原始设计内容，不以套框为由重算工程量或删除模型对象。
- 底座返回未知写入、保存验证失败或保护状态时，保留请求身份并读状态；禁止换COM、任意Lisp或重放整页绕过保护。通道选择在开始前说明，已受保护的图纸不能靠切换通道解锁。
- 现有视口任何修改前确认所属布局且为工作视口；纸空间整体视口不能改成工作视口。只读检查不得顺手激活、解锁或重取景。
- 按DWG原始数值操作。模型WCS、视图DCS、纸空间坐标和纸张打印比例分别理解；未知INSUNITS不自动换算。
- 正常字体替代产生宽窄变化不单独判失败。文字可读、内容正确即可进入后续排版，由Agent调整字高宽度与位置。遇到缺字按实际任务处理；不得声称底座严格保存限制已修改。
- 缺图先查模型、块、属性及相关文件，再记录待补；占位需任务授权，不能伪造设计内容。删页限定已指定布局/目录条目，不连带删除工程实体或外参源文件。

## 按需资源

- 新项目、续作、目录匹配及增减图幅：[页清单与维护](references/catalogue.md)。
- 原生COM支持Windows+Python+pywin32，连接已打开目标，不自动启动/关闭CAD；`scripts/inspect_cad.py --help`查看只读清点入口。
- `scripts/frame_candidates.py`只列候选文件和日期线索，不自动选版、不修改CAD。
- `scripts/compare_model_inventory.py`可比对清点导出的模型字段；仅在需要保护核对时使用，不是全语义验证，也不是每页强制关卡。
- 验证与继承范围：[validation.md](references/validation.md)。旧321项目是经验来源，不是新项目配置；本包不携带项目图纸、字体、签名或工程目录。
