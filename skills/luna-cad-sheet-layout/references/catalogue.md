# 页清单、查图及增减图幅

## 最小工作记录

Agent维护JSON或表格即可，不要求搭建数据库。图号可能改变，另给每个物理图幅稳定sheet_id；不要用当前行号或总页数作为唯一身份。

```json
{
  "backend": "native-com",
  "cad_progid": "AutoCAD.Application.24.1",
  "guidance": "guided",
  "frame": {"path": "<已核实的绝对DWG路径>", "revision_basis": "<用户指定或文件名日期>", "paper_mm": [420,297]},
  "sheets": [{
    "sheet_id": "sheet-a",
    "dwg": "<工作副本绝对路径>", "layout": "<实际布局名>",
    "number": "<实际图号>", "title": "<实际图名>",
    "page": 1, "pages": 1,
    "action": "frame", "status": "planned",
    "title_bindings": [], "viewport_handles": [],
    "last_saved": null, "evidence": []
  }]
}
```

420×297只是A3示例。title_bindings记录布局、对象句柄、DBText/MText或块属性tag以及字段用途；不推断所有模板结构相同。视口参数单独记录纸上中心/宽高、WCS内容中心、CustomScale、冻结层和锁定。句柄只在对应DWG身份内有效。

## 按目录套图

读目录真实图号、图名、页数，先匹配文件与图中内容，再填布局与图签绑定。大小写/空格可辅助检索，但重名、版本冲突要保留候选，不能用模糊匹配静默决定。目录写“未完成”的页若现场已存在，先核实再更新状态，不重复创建。

先输出映射和本次动作，再按已授权任务执行；清单不是又一次必须用户批准的流程。仅出现无法由现有资料判断的关键冲突才问。完成后核对实际图签与目录，不以清单自洽代替CAD读回。

## 查图

从现有清单按图号/图名/布局/文件查；没有清单则清点布局、文本与属性。返回完整路径、布局、读到的图签和证据；未读到要区分未加载外参、代理不可读与确实没有。只为查图不切布局解锁取景、不另建页。

## 新增图幅

沿用已确认框版本与页样式，分配新sheet_id；明确新图内容、图号与插入顺序。创建缺失布局/视口，补图签，更新受影响目录及分页。已通过页面不重做；需要重编号的现有页仅改对应图签字段。

## 删除图幅

按用户已指定范围处理。先确认精确DWG、布局、原图号和是否仍需保留该内容。可用退出出图清单/归档代替删除布局，依任务意图选择并如实说明；真正删布局先留工作副本检查点。禁止删Model、工程模型对象、共享外参源文件，禁止按“看着很小”删除视口。当前COM helper没有delete_sheet方法，Agent通过明确原生布局Delete操作，或保留待删状态；底座未支持时不要杜撰接口。

## 图号、图名与页数统一

改名独立维护文件名、布局名、图签图名和目录条目；它们不一定要求同名，不擅自批量重命名文件导致外参断链。多幅同一图号时用page/pages区分；目录通常汇总该图号物理页数，目录自身/封面是否计入按项目约定，不继承321的算法。

重排图号先在清单形成最终映射，检查碰撞与遗漏，再改明确绑定字段；布局顺序只有任务需要才改。目录表格和CAD不能跨应用原子提交，任一侧失败记录已完成一侧及待补字段，不宣称同步成功，也不重放CAD整套写入。
