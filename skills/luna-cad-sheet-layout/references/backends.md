# 后端选择与底座衔接

## 开始前说明一次

优先发现已连接底座的真实工具和schema，确认版本、目标文档及保护状态。以下能力表是2026-10-16本地1.2.0-beta.1的源码盘点，不能替代未来版本的实际发现。不要凭此表猜工具名/请求字段。

|任务|当前底座|技能处置|
|---|---|---|
|模型图形、代理基础几何、已知句柄属性|已有相应读取；代理可能partial/unavailable|用实际结果判断内容；不要把不可读当缺图|
|原生基本图元、模型文字和全局图层|已有有界操作|复用明确支持的操作，不用全局冻结模拟单视口隐藏|
|按布局枚举纸空间实体、创建/选择布局、纸空间图签编辑|尚不完整|底座单独无法完成套框闭环|
|工作视口创建、取景、锁定、只读快照、单视口冻结|无完整专用原语|明确原生COM路径，或停在方案/待执行状态|
|图框外参挂接/相对路径/加载状态|普通block_insert不能替代|不得伪造“已挂接”成功|
|page_setup、plot_pdf|已有但打印范围/当前布局/单位受限|按真实schema检查；不能改INSUNITS绕过|
|保存|仍有严格符号表读回约束|正常字体变化可能阻塞，保留请求保护；未修复不能当作已放宽|

## 可选执行路径

**底座路径**：能力足够的任务用MCP绑定、读取、计划执行和读回，沿用其文档身份、稳定请求ID、原图保护及未知写入规则。若新版本已补原语，Agent按实际schema使用，不需要另写套框算法。

**原生COM路径**：当前完整套框的可用经验路径。用户授权CAD套框且项目规则允许时，在开始前明确说明底座缺哪些操作、本轮改用COM覆盖哪些步骤。项目要求额外许可时遵守它；不得默默切换。使用本包Session精确匹配已打开完整路径，显式选择ProgID，不自动连接其它版本、不自动开关CAD。一个DWG的写入保持同一后端。

COM不享有底座的事务、请求日志或磁盘几何验证保证；用工作副本、操作记录、必要读回和图面抽查弥补，不宣称同等保证。没有COM或CAD环境时，可完成清单与映射准备，执行状态保留未验证。

**受保护图纸**：任何底座写入未知、保存验证失败、fence/保护未解除，均不得换后端继续该图。可整理资料或处理无关副本任务，但不能将复制/重开作为重放原请求的办法。

## 真正需要补底座时

先限定一个具体阻塞操作，提出“目标对象/归属、明确输入、真实返回、失败行为”的小契约。优先顺序：纸空间枚举及目标 → 布局与工作视口基础操作 → 本地外参挂接与状态 → 单视口层状态 → 当前页打印。均由Agent给明确参数；不开发自动分幅、自动拼路、审美评分或整套套框引擎。

本技能改造只做衔接说明和原生路径复用，未新增这些MCP接口。2026接口兼容与实机验证范围见validation.md。
