# Luna CAD Sheet Layout

**Luna CAD 智能体套图排版技能**

**让 AI 智能体完成 CAD 施工图最后一道整理工序。**

工程设计和CAD绘图已经完成，但图框、布局分幅、视口比例、图号图名和图纸目录还没整理好？本技能把这段收尾流程交给已有的AI Agent：智能体读取实际图纸、规划页面、调用CAD原生操作，再检查交付结果。

它是**面向AI Agent的可执行Skill**，由任务指导、已有脚本和实战经验组成；不是独立AI Agent，也不是传统的一键套图框插件。

## 高低算力双模式

|模式|怎样指导|
|---|---|
|**低算力分步模式，默认**|提供明确步骤、可复用脚本、常见失败案例及恢复经验；按当前步骤推进，避免从头反复研究。|
|**高算力简明模式**|只保留目标、主要流程、必要边界和关键检查点；智能体自主决定操作，需要时再读详细踩坑资料。|

由智能体按自身能力和任务复杂程度选择或切换，不绑定模型名称。低算力模式旨在减少反复试错，目前没有独立成功率或token节省比例的对照结论。

经验来自真实AutoCAD套框经历，包括误改纸空间整体视口、跨图复制后外参未加载、插入单位放大、单视口冻层、裁切边缘旧字残影，以及只读检查误触发解锁和状态变化。

## 从设计成图到交付整理

- **找框、选框、挂框：** 智能体检索候选外参及日期线索，优先考虑较新修订，最终按实际适用性选择，不把修改时间直接当正式最新版。
- **套图与排版：** 按实际设计内容和目录组织图幅、布局及工作视口，确定取景和比例；保留已经正确的页面。
- **图签与目录一致：** 对应图号、图名、当前页与总页数，维护目录和实际图幅。
- **查图与续作：** 定位已有图纸，增加、删除或调整图幅，仅更新受影响的编号、标题和目录项。
- **保护与交付：** 保留工程设计成果，保存可追踪的DWG修改，输出PDF并按任务要求抽查，报告未完成项。

这些工作由智能体判断并调用明确操作完成；本包不把它们宣称为无人干预的整套批处理，也不代替工程设计。

## Skill与底座各做什么

Skill指导智能体理解任务、判断图纸、规划套图和调用工具；CAD Agent Foundation提供通用CAD原生操作。优先复用底座，但底座不是唯一执行条件。

当前评估的本地底座1.2.0-beta.1尚缺完整的纸空间、布局、工作视口和外参操作。对应环节保留已有AutoCAD2022实战依据的原生COM路径，执行前明确选择后端。不能在底座未知写入、保存验证失败或保护状态下换通道绕过限制。本轮没有扩大底座开发范围。

## 安装与调用

将仓库的`skills/luna-cad-sheet-layout`复制到Agent配置的技能目录，例如`~/.codex/skills/luna-cad-sheet-layout`，然后刷新技能发现。也可解压技能专用ZIP；仓库ZIP需取其中`skills/`下的技能目录，不能把整仓库当成技能安装。

需要已安装的AutoCAD、工作副本、目录和可用图框；COM路径需要Windows及Python/pywin32。技能不附带CAD、模型运行时、工程DWG、商业字体或签名图框。

> 使用 $luna-cad-sheet-layout，按低算力分步模式整理这些已完成设计的DWG和图纸目录，查找并选择适用的最新修订图框外参，完成套图排版并统一图号图名；保留正确页面，按类型抽查。

> 使用 $luna-cad-sheet-layout，采用高算力简明模式，按实际内容自主确定布局、视口取景和比例，需要时再查踩坑资料，报告交付结果与剩余限制。

## 当前状态

版本**3.0.0-beta.1**。继承旧项目AutoCAD2022 COM实战记录，已有18项针对性离线测试；新技能尚未完成AutoCAD2026套图排版实图验证，也未完成低算力Agent独立全流程验证。旋转/三维视口fit不支持，代理内容读取依赖真实后端能力。

正常字体变化允许由Agent后续调整，但本轮未修改底座严格字体保存校验。完整验证范围见[记录](skills/luna-cad-sheet-layout/references/validation.md)。以beta预发布形式分发，见[GitHub仓库](https://github.com/capskov/luna-cad-sheet-layout)及[发布页面](https://github.com/capskov/luna-cad-sheet-layout/releases)；许可证尚待作者选择。
